# Oscar Race Lab (가칭)

2000–2026년(제72–98회) 아카데미 **작품상 레이스**를 주요 전초전 결과의 누적으로 탐색하는 개인용 정적 데이터 웹사이트.
“누가 받았나”를 나열하는 대신, 전초전과 작품상이 언제 일치하고 언제 갈렸는지를 데이터로 확인하게 만드는 것이 목적이다.

- 사이트: `docs/` (서버 없음, 순수 HTML/CSS/JS, 외부 라이브러리 없음)
- 설계서: [`research/DESIGN.md`](research/DESIGN.md) — 상의 의미, 시즌 정렬, 스키마, 출처, 함정, 페이지 구조
- 예측 확률·배당률·여론 수치는 만들지 않는다. 실제 수상 결과의 누적만 보여준다.

## GitHub Pages로 열기

1. 이 브랜치(또는 병합 후 `main`)를 GitHub에 push
2. 저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch**
3. Branch: 해당 브랜치, Folder: **`/docs`** → Save
4. 몇 분 뒤 `https://<계정>.github.io/<저장소>/` 에서 열림

`docs/.nojekyll`이 있어 Jekyll 처리 없이 그대로 서비스된다. 데이터가 `data/orl-data.js`로 함께 번들되어 있어 `docs/index.html`을 로컬 파일로 열어도 동작한다.

## 데이터에서 확인된 것 (2000–2026, 27시즌, 기본 규칙 기준)

결론을 먼저 정하지 않고 집계한 결과다. 표본이 27개뿐이라 1~2시즌 차이는 순위를 바꿀 수 있다.

- **작품상 일치율**: PGA 20/27, DGA 19/27, Critics Choice 19/27, SAG 앙상블 14/27, 골든글로브(두 부문 중 하나) 14/27(드라마 10, 뮤지컬·코미디 4), BAFTA 12/27. 각본 지표 WGA(둘 중 하나)는 15/27.
- **“PGA가 가장 정확하다”는 통념**: 이 데이터에서 PGA가 가장 자주 일치한 것은 맞지만 DGA·Critics Choice보다 1시즌 많을 뿐이다. 이 차이로 PGA가 확실히 더 정확하다고 말할 수는 없다.
- **PGA 수상작이 작품상을 놓친 해**: 2002, 2005, 2006, 2007, 2016, 2017, 2020. 2014년은 PGA 공동 수상(*12 Years a Slave* / *Gravity*) 중 한 편이 작품상.
- **수렴한 해**(한 영화가 핵심 기관 5개 이상 수상): 11시즌. 그중 수렴한 영화가 작품상을 놓친 경우는 2006 *Brokeback Mountain*, 2017 *La La Land* 2번.
- **갈린 해**(최다 수상작도 3개 이하): 2002, 2005, 2007, 2015, 2016, 2018, 2019, 2025.
- **전초전 최다 수상작(오스카 직전 기준)이 작품상을 놓친 시즌**: 2005, 2006, 2016, 2017, 2019, 2020, 2022.
- **전초전 성적이 약했는데 작품상을 받은 영화**(핵심 기관 1개 이하): *Million Dollar Baby*(2005), *Crash*(2006), *Moonlight*(2017), *Parasite*(2020).
- **초반 선두**(첫 2개 전초전 기준)**와 작품상 수상작이 달랐던 시즌**: 2005, 2006, 2011, 2015, 2017, 2020.
- **SAG 앙상블 없이 작품상을 받은 영화**: 13/27. 그중 2018 *The Shape of Water*, 2019 *Green Book*, 2021 *Nomadland*는 앙상블 후보에도 오르지 못했다.

## 검증 수준과 한계

- 1차 출처: 영어 위키백과 부문별 목록 페이지(리비전 고정). 영화 식별은 제목 문자열이 아닌 위키백과 문서 → Wikidata QID로 한다(리메이크·동명 영화 오연결 방지). 원 표기는 별칭으로 보존한다.
- 2차 대조: 같은 위키백과의 회차별 문서와 자동 대조. 270개 부문×시즌 중 242개 일치, 27개는 형식 차이로 대조 불가, 1개는 도구 오탐(수동 확인 결과 충돌 없음).
- 공식 DB 직접 대조는 하지 않았다. oscars.org와 bafta.org는 이 작업 환경에서 403으로 막혔고, 나머지 공식 사이트는 “실제 충돌이 발견된 항목만 추가 검증” 방침에 따라 생략했다. 대신 위키백과가 인용한 공식 URL을 레코드마다 붙였다.
- 자격 없음(`I`)은 골든글로브 외국어 규정(2023년 시즌까지)처럼 **문서화된 근거가 있을 때만** 표시한다. WGA 자격은 개별 확인하지 않았다(후보 아님 ≠ 탈락일 수 있음).
- 오스카 이후 개최된 시상식(BAFTA 2000, WGA 2024)은 선두 계산에서 제외하고 일치율에서는 옵션으로 제외할 수 있다.
- 모든 주의사항은 사이트의 `#/data` 화면과 `data/build/issues.json`에 있다.

## 다시 만들기

```bash
# 1) 원자료 스냅샷 (이미 data/raw/wikipedia 에 있음. 새로 받을 때만)
python3 scripts/fetch_wikipedia.py "Academy Award for Best Picture" ...
# 2) 파싱 → 영화 식별 → 교차 대조 → 빌드 → 검증
cd scripts
python3 parse_wiki_awards.py
python3 resolve_films.py
python3 crosscheck_ceremony_pages.py
python3 build_dataset.py
python3 validate_data.py
cd ..
node scripts/export_analysis.js          # 분석 레이어 요약 출력 + docs/data/orl-analysis.json
NODE_PATH=$(npm root -g) node scripts/smoke_test.js   # (선택) Playwright로 모든 화면 점검
```

## 확장 제안 (구현하지 않음)

작품상 버전이 끝난 뒤 검토할 만한 방향:

1. **초반 시즌 신호 추가**: TIFF 관객상, 뉴욕·LA 비평가협회, NBR. 지금의 “초반 선두”는 Critics Choice·골든글로브 기준이라 실제 가을 레이스를 반영하지 못한다.
2. **다른 부문으로 확장**: 감독상(DGA와 직접 대응), 연기상(SAG 개인상), 각본상(WGA와 직접 대응). 스키마는 부문을 추가하는 방식으로 그대로 쓸 수 있다.
3. **후보 발표일 이벤트**: 전초전별 후보 발표일을 넣어 “후보 단계의 레이스”까지 타임라인에 표시.
4. **오스카 투표 기간 반영**: 최종 투표 마감일을 넣어 “투표 전에 알려진 결과만” 세는 옵션.
5. **공식 DB 대조 확대**: 접근 가능한 환경에서 oscars.org / BAFTA 데이터베이스와 자동 대조.
6. **1990년대 이전 시즌**: 선호투표 도입(2010) 전후 비교를 위해 기간 확장.
