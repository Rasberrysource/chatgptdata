# chatgptdata

**AI 잡동사니 결과물들.**

챗지피티 데이터 추출용일 뻔했지만, 지금은 AI와 함께 만든 이런저런 결과물을 모아 두는 저장소입니다.

영화 기록에서 취향을 찾아보거나, 오스카 전초전 결과를 들여다보거나, 광고에서 보던 게임을 직접 만들어 보기도 합니다. 웹사이트, 게임, 데이터 분석처럼 주제와 형태가 서로 다른 개인 실험들을 프로젝트별로 보관합니다.

## 파일을 내려받아 열기

**Oscar Race Lab**은 위의 웹사이트 링크로 바로 열 수 있습니다.

**Letterboxd 취향 분석**과 **좀비 게이트 러너**는 해당 프로젝트의 **코드와 설명** 링크를 연 뒤, **Code → Download ZIP**으로 내려받아 압축을 풀고 아래 파일을 브라우저로 열면 됩니다.

| 프로젝트 | 열 파일 |
|---|---|
| Letterboxd 취향 카드 | `cards/index.html` |
| Letterboxd 숨은 패턴 분석 | `cards/patterns.html` |
| 좀비 게이트 러너 | `lastwar-ad-runner/index.html` |

완성된 HTML 결과물을 보는 데에는 별도 설치나 빌드 과정이 필요 없습니다. 데이터를 다시 분석하거나 코드를 수정하려면 각 프로젝트의 README를 참고하세요.

## 브랜치 안내

- **`main`**: 저장소 소개와 프로젝트 목록을 담은 입구입니다.
- **프로젝트별 브랜치**: 위 표의 **코드와 설명** 링크에 실제 코드와 결과물, 개별 README가 있습니다.
- **GitHub Pages**: 현재 이 저장소의 웹사이트 주소에는 **Oscar Race Lab**이 게시되어 있습니다.

원하는 프로젝트를 내려받을 때는 먼저 해당 브랜치로 이동하세요. `main`을 내려받으면 이 안내문만 들어 있습니다.
