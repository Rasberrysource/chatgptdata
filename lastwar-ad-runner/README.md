# 좀비 게이트 러너

《라스트 워: 서바이벌》 광고에 나오는 미니게임을 HTML5로 재현한 게임입니다.
숫자 게이트를 골라 부대를 불리고, 게이트 숫자를 쏴서 키우고, 좀비 무리와 보스를 뚫고 나가는 러너입니다.
원작과 관계없는 비공식 팬 제작물이며, 원작의 이름, 로고, 그림, 소리는 쓰지 않았습니다.

## 실행

- `index.html`을 브라우저로 열면 됩니다. 설치나 빌드 과정은 없습니다.
- 인터넷이 없어도 돌아갑니다. 제목용 웹 폰트만 못 불러오고 시스템 글꼴로 대체됩니다.

## 조작

| 입력 | 동작 |
|---|---|
| 화면 좌우 드래그 | 부대 이동 |
| ← → 또는 A D | 부대 이동 (키보드) |
| P 또는 Esc | 일시정지 |

사격은 자동입니다. 병사가 많을수록 한 번에 나가는 총알이 많아집니다.

## 들어 있는 것

- **스테이지 30개**
  - 1~5스테이지는 요소를 하나씩 소개하는 튜토리얼이고, 6스테이지부터는 시드 기반 자동 생성입니다.
  - 남은 병사 수로 별 1~3개를 받습니다.
- **무한 모드**: 끝없이 달리고 5,000m마다 보스가 나옵니다. 최고 점수를 저장합니다.
- **타이틀 데모**: 광고처럼 일부러 틀린 문(÷2)을 골라 전멸하는 장면이 반복 재생됩니다.
- **게임 요소**
  - `+ − × ÷` 게이트와 숫자 쏘기
  - 배럴 5종: 병력, 무기, 연사, 폭탄, 빙결
  - 무기 6단계: 권총 → 레이저
  - 좀비 무리 3종, 거대 좀비, 장애물 3종, 보스(10스테이지부터 졸개 소환)
- **진행 저장**: 브라우저 `localStorage`에 저장됩니다.

## 파일

```
index.html        진입점
css/style.css     화면 스타일
js/core.js        규칙과 시뮬레이션 (DOM 없음, Node에서도 동작)
js/stages.js      스테이지 생성기와 보정표
js/bot.js         자동 플레이 봇 (타이틀 데모, 밸런스 검증)
js/render.js      원근 캔버스 렌더러
js/audio.js       WebAudio 합성 효과음
js/app.js         화면 전환, 입력, 게임 루프, 저장
tools/balance.js  봇으로 전 스테이지를 돌려 보는 밸런스 도구
docs/design.md    기획서 (조사 결과 포함)
```

## 밸런스 도구

Node 18 이상이 필요합니다.

```
node tools/balance.js              # 30개 스테이지를 봇 3종으로 돌린 결과표
node tools/balance.js 1 5          # 1~5스테이지만
node tools/balance.js --calibrate  # 보스 보정값을 다시 계산해 js/stages.js용 표를 출력
```
