# BIFF 2026 부산 여행 일정 앱

2026 부산국제영화제(10/7~10/13) 여행 동안 휴대폰으로 일정을 빠르게 확인하는 개인용 앱입니다.
서버 없이 파일만으로 동작하고, 한 번 열어 두면 **인터넷이 끊겨도** 모든 일정을 볼 수 있습니다.

- **오늘**: 다음 일정, 남은 시간, 늦어도 몇 시에 출발해야 하는지
- **일정**: 전체 요약과 날짜별 타임라인 (영화, 기차, 이동, 식사 가능 시간, 체크인·아웃). 좌우로 밀면 날짜가 바뀝니다.
- **영화**: 예매한 영화 목록, 날짜순·제목순 정렬, 끝난 영화에 봄·못 봄 체크
- **장소**: 숙소, 상영관, 부산역 주소와 지도 링크
- **체크**: 준비물 체크리스트

기획 내용(확정 일정, 빠듯한 구간, 확인되지 않은 정보)은 [PLAN.md](PLAN.md)에 있습니다.

## 실행 방법

### 휴대폰에서 쓰기 (추천)
1. 아래 **GitHub Pages 배포**를 마치면 주소가 하나 생깁니다.
2. 갤럭시에서 그 주소를 **Chrome**(또는 삼성 인터넷)으로 엽니다.
3. 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**를 누릅니다.
4. 이제 홈 화면 아이콘으로 앱처럼 열립니다. **출발 전에 와이파이에서 한 번 열어 두면** 부산에서 인터넷이 안 돼도 일정이 다 보입니다.

### 컴퓨터에서 미리 보기
- 가장 간단한 방법: `index.html`을 더블클릭합니다. 일정은 다 보이지만 오프라인 저장과 설치 기능은 동작하지 않습니다.
- 휴대폰과 똑같이 확인하려면 이 폴더에서 터미널을 열고 아래를 입력한 뒤, 브라우저에서 `http://localhost:8000` 을 엽니다.
  ```
  python3 -m http.server 8000
  ```

### 여행 날짜처럼 미리 보기
주소 끝에 `?now=날짜T시각`을 붙이면 그 시각 기준으로 화면을 볼 수 있습니다.
예: `…/biff2026/?now=2026-10-12T14:20` (10월 12일 오후 2시 20분처럼 보기)
화면 위에 파란 '미리보기' 표시가 뜨고, **해제**를 누르면 실제 시각으로 돌아옵니다.

## GitHub Pages 배포 방법

> ⚠️ 이 저장소(`chatgptdata`)는 **비공개**입니다. GitHub 무료 요금제에서는 비공개 저장소로 Pages를 만들 수 없습니다.
> 그리고 Pages 주소는 **주소를 아는 누구나 열 수 있습니다**(숙소 이름과 일정이 보임). 주소는 남에게 공유하지 마세요.

### 방법 A: 앱 전용 공개 저장소 만들기 (무료, 추천)
1. GitHub에서 **New repository** → 이름 예: `biff2026` → **Public** → Create.
2. 새 저장소 화면에서 **Add file → Upload files**를 누르고, 이 `biff2026` 폴더 **안의 파일과 icons 폴더**를 통째로 끌어다 놓습니다. `index.html`이 저장소 맨 위에 오게 하세요. 그다음 **Commit changes**를 누릅니다.
3. 저장소 **Settings → Pages**로 갑니다.
   - Build and deployment → Source: **Deploy from a branch**
   - Branch: **main**, 폴더: **/ (root)** → **Save**
4. 1~2분 뒤 같은 화면 위쪽에 주소가 나옵니다. 예: `https://rasberrysource.github.io/biff2026/`

### 방법 B: 지금 저장소에서 바로 (GitHub Pro 이상일 때)
1. 이 작업 브랜치를 기본 브랜치에 합칩니다(Pull Request → Merge).
2. **Settings → Pages** → Source: Deploy from a branch → 합친 브랜치 / **/ (root)** → Save
3. 주소: `https://rasberrysource.github.io/chatgptdata/biff2026/`

앱은 어느 하위 주소에 올려도 동작하도록 모든 경로를 상대 경로로 만들었습니다.

## 일정 고치는 법 (`schedule.js`)

GitHub 웹에서 고치는 것이 가장 쉽습니다. `schedule.js` 파일을 열고 → 연필(✏️) 아이콘 → 고치고 → **Commit changes**.
그다음 휴대폰에서 앱을 열면 위쪽에 **"새 일정 데이터가 준비됐어요"** 안내가 뜹니다. **새로고침**을 누르면 반영됩니다.

### 꼭 지킬 규칙 4가지
1. 글자는 `"큰따옴표"` 안에 씁니다. 예: `제목: "천사의 알"`
2. 숫자와 `true`/`false`는 따옴표 없이 씁니다. 예: `러닝타임: 72`, `예매: true`
3. 한 항목 `{ ... }` 뒤에는 쉼표 `,`를 붙입니다.
4. `//` 뒤의 글은 메모입니다. 앱에 영향이 없습니다.

날짜는 `"10-07"`, 시각은 24시간제 `"13:30"`으로 씁니다.
실수하면 앱 맨 위에 **빨간 안내**가 떠서 어느 영화나 줄이 잘못됐는지 알려 줍니다. 화면이 통째로 비어 있으면 마지막으로 고친 곳의 쉼표, 따옴표, 괄호를 확인하세요.

### 영화 시간 변경하는 법
`영화: [` 아래에서 해당 영화 줄을 찾아 **시작**, **날짜**, **장소**, **관**만 바꿉니다. 종료 시각은 앱이 자동으로 계산합니다.

```js
// 바꾸기 전
{ 코드: "487", 날짜: "10-12", 시작: "15:30", 제목: "어크로스: 전쟁은 어떻게 잊혀지는가", 러닝타임: 90, 장소: "CGV센텀시티", 관: "1관", GV: false, 예매: true },
// 바꾼 후 (15:40, 2관으로 변경된 경우)
{ 코드: "487", 날짜: "10-12", 시작: "15:40", 제목: "어크로스: 전쟁은 어떻게 잊혀지는가", 러닝타임: 90, 장소: "CGV센텀시티", 관: "2관", GV: false, 예매: true },
```

- **장소**는 `장소목록`에 있는 이름 중 하나여야 합니다: `"영화의전당"`, `"CGV센텀시티"`, `"롯데시네마 센텀시티"`, `"소향씨어터"`, `"부산역"`, `"숙소"`
- GV가 새로 생기면 `GV: true`로 바꿉니다. 종료 시각에 GV 30분이 더해집니다.

### 영화 추가하는 법
- **현장 판매나 취소표로 후보 영화를 예매했다면** 코드를 고칠 필요가 없습니다. 앱의 **일정 → 그 날짜 → 미예매 후보**에서 스위치를 켜면 일정에 들어갑니다. 이 설정은 그 휴대폰에만 저장됩니다.
- 파일에서 추가하려면 비슷한 영화 줄 하나를 **복사해서 바로 아래에 붙여 넣고** 내용을 바꿉니다. 예매한 영화면 `예매: true`로 씁니다.

```js
{ 코드: "999", 날짜: "10-10", 시작: "14:00", 제목: "새 영화", 러닝타임: 100, 장소: "영화의전당", 관: "소극장", GV: false, 예매: true },
```

- 묶음상영은 `러닝타임: "96+17"`처럼 씁니다.
- 코드는 영화마다 달라야 합니다(봄·못 봄 체크가 코드로 저장됩니다).

### 영화 삭제하는 법
- 예매를 취소했다면 그 줄의 `예매: true`를 `예매: false`로 바꿉니다. 일정에서 빠지고 '미예매 후보'에만 남습니다.
- 완전히 지우려면 `{`부터 `},`까지 그 줄을 통째로 지웁니다.

### 숙소 변경하는 법
1. `장소목록` 안의 `"숙소": { ... }`에서 **이름**, **주소**, **지도검색어**를 바꿉니다. **위도·경도**를 알면 바꾸고, 모르면 두 줄을 지웁니다.
   - 위도·경도 찾는 법: 구글 지도에서 숙소를 길게 누르면 `35.18354, 129.12212` 같은 숫자가 나옵니다. 앞이 위도, 뒤가 경도입니다.
2. `숙소: { ... }`에서 **체크인날짜**, **입실가능**, **체크아웃날짜**, **퇴실마감**을 예약 내역대로 바꿉니다. 확인했으면 `시간확인됨: true`로 바꿉니다.
3. `이동시간` 목록에서 `"숙소"`가 들어간 줄의 분(分)을 새 숙소 기준으로 고칩니다. 모르겠으면 그 줄들을 지우세요. 위도·경도가 있으면 앱이 직선거리로 대략 추정하고 '(좌표로 추정)'이라고 표시합니다.

### 이동 시간 고치는 법
`이동시간`의 각 줄은 `[장소A, 장소B, { 방법: [최소분, 최대분] }]` 형식입니다. 양방향에 똑같이 적용되고, **맨 앞의 방법**이 기본값입니다. '늦어도 몇 시 출발'과 ⚠ 경고는 이 방법으로 계산합니다.

```js
["숙소", "영화의전당", { 도보: [20, 30], 택시: [7, 12] }],
```

### 계산 기준 바꾸기 (`설정`)
| 항목 | 기본값 | 뜻 |
|---|---|---|
| 영화입장여유 | 15 | 상영 몇 분 전에 도착할지 (영화 줄에 `입장여유: 30`을 쓰면 그 영화만 따로 적용) |
| 기차여유 | 15 | 기차 출발 몇 분 전에 역에 도착할지 |
| GV예상시간 | 30 | GV 길이 추정 (공식 발표 없음) |
| 최소식사시간 | 30 | 이보다 짧은 빈 시간은 식사로 추천하지 않음 |
| 여유식사시간 | 60 | 이 이상이면 '식사 가능', 이보다 짧으면 '간단한 식사만 가능' |
| 이동여유경고 | 15 | 출발까지 여유가 이보다 적으면 ⚠ 표시 |

## 여행 직전에 확인하고 고칠 것

- [ ] **숙소 입실·퇴실 시각**: 지금은 여기어때 상품 기준 추정(입실 17:00, 퇴실 12:00)입니다. 예약 내역을 보고 `숙소`의 `입실가능`, `퇴실마감`을 고치고 `시간확인됨: true`로 바꾸세요.
- [ ] **숙소 연박 조건**: 낮에 퇴실했다가 다시 들어가는 조건이 있는지, 10/7 체크인 전과 10/13 체크아웃 후에 짐을 맡길 수 있는지 확인하세요.
- [ ] **숙소 전화번호**: `장소목록 → "숙소" → 전화`에 적으면 장소 화면에서 바로 전화를 걸 수 있습니다.
- [ ] **영화 시간·상영관 변경**: BIFF 공지나 예매 내역에서 확인하세요.
- [ ] **러닝타임 2편**: 미친 노인의 일기(자료 118분, 공식 120분), 이성과 감성(자료 131분, 공식 133분). 지금은 자료 값입니다. 공식 값으로 바꾸려면 숫자만 고치면 됩니다.
- [ ] **기차 열차번호·좌석**: `기차`의 `메모`에 적어 두면 타임라인에 보입니다.
- [ ] **10/13 짐 계획**: 영화 뒤 부산역까지 지하철로 가면 여유가 약 7분이라 택시를 권장합니다.

## 알아 두면 좋은 것

- **종료 시각** = 시작 + 러닝타임(광고 없음 가정). GV 영화는 30분을 더해 'GV 포함'으로 따로 보여 줍니다.
- **이동 시간**은 실시간 교통이 아니라 미리 정한 범위입니다. 택시 대기 시간은 빠져 있습니다.
- **식사 가능 시간**은 두 일정 사이에서 이동 시간(최대치)과 입장 여유를 빼고 계산합니다.
- **봄·못 봄, 체크리스트, 현장 예매 스위치, 정렬 방식**은 그 휴대폰 브라우저에만 저장됩니다(localStorage). 다른 기기와 공유되지 않고, 브라우저 데이터를 지우면 사라집니다.
- **파일을 새로 추가하거나 이름을 바꿨다면** `sw.js` 맨 위의 `VERSION`(예: `biff26-v1` → `biff26-v2`)과 `CORE` 목록을 함께 고치세요. `schedule.js`만 고쳤다면 필요 없습니다.
